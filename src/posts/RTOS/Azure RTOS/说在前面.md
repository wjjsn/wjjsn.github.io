# 为什么要做这个项目
1. 对自身能力的提升，查缺补漏，后续忘记方便查询
2. 其他同类视频要么过于啰嗦要么先从难的地方教起
网上同样也有很多好教程，比如韦东山的，硬汉嵌入式的。但是我去看了，韦东山讲的是在是太啰嗦了，把每一个来学的都当做零基础的来教，基础的内容学完了之后能主动学习更深入内容的人肯定都是有基础的。硬汉的教程我觉得顺序不好，上来就把怎么移植一个RTOS教了，然后开始教ARM内核，中断原理，甚至汇编等等。不能说这些内容不重要吧，这些都是很重要的，能学会这些当然能在这条路上走的更远。但是学技术我觉得对于入门的人来说最重要的是快速开始进行应用层开发。当能把一个东西的应用层开发弄明白了，后续再去学习怎么移植，再深入这些东西的源码，对于RTOS的详细配置信息，内核，这样学起来效果会更好。
# 学习的方法

1. 我说你听
2. 你说我听
3. 我做你看
4. 你做我看
