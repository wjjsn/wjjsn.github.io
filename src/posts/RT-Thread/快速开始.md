# 拉取仓库
在[Release v2.0.0 · RT-Thread/env-windows](https://github.com/RT-Thread/env-windows/releases/tag/v2.0.0)下载离线版本并安装，联网安装依赖版本可能有bug
在[RT-Thread/rt-thread: RT-Thread is an open source IoT Real-Time Operating System (RTOS). https://rt-thread.github.io/rt-thread/](https://github.com/RT-Thread/rt-thread/releases/tag/v5.2.1)下载发行版
下面以版本5.2.1，BSP为stm32f407-lckfb-skystar为例
# 构建工程
运行`env.exe`，将目录切换到`*\rt-thread-5.2.1\bsp\stm32\stm32f407-lckfb-skystar`，运行`pkgs --update`命令升级包。运行`scons --target=mdk5`命令生成礦ision5 Project，也可以指定其他的参数生成其他IDE或构建工具的工程。
RT-Thread是以BSP为工程进行构建的，不要随便改变BSP的目录。
已经有BSP的板子可以在构建完成后进行烧录测试。非常不推荐使用暂时没有BSP支持的板子，因为适配起来比较麻烦。
