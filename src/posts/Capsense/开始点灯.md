![选择创建新BSP还是使用现有BSP](/posts/assets/Capsense/image.png)
如果板子不是评估板，是自己画的，创建一个新的bsp，否则直接选择对应的bsp
![选择使用现有BSP](/posts/assets/Capsense/image-1.png)
![继续配置BSP](/posts/assets/Capsense/image-2.png)
选择自己的芯片并且起一个名字
![选择芯片并命名](/posts/assets/Capsense/image-3.png)
添加capsense库（点灯是不需要的，但是玩psoc迟早用上的）
![添加CAPSENSE库](/posts/assets/Capsense/image-4.png)
选择刚刚创建好的bsp，继续
![选择刚创建的BSP继续](/posts/assets/Capsense/image-5.png)
选择blinky例程。

打开工程文件夹，打开`bsps\TARGET_test\config\design.modus`改引脚。

随便选一个引脚，选推挽输出。

![在Device Configurator中选择引脚配置推挽输出](/posts/assets/Capsense/image-6.png)


![打开CAPSENSE组件并配置](/posts/assets/Capsense/image-7.png)
打开capsense，随便添加一个组件，随便分配好引脚，并且根据底部的指引把报错解决了

^S，保存并重新生成代码

改主函数，把默认的引脚改了。
```diff
diff --git a/main.c b/main.c
index aaddcf3..36200e3 100644
--- a/main.c
+++ b/main.c
@@ -85,7 +85,7 @@ int main(void)
     for(;;)
     {
         /* Toggle the user LED state */
-        Cy_GPIO_Inv(CYBSP_USER_LED_PORT, CYBSP_USER_LED_PIN);
+        Cy_GPIO_Inv(ioss_0_port_0_pin_0_PORT, ioss_0_port_0_pin_0_PIN);

         /* Wait for 0.5 seconds */
         Cy_SysLib_Delay(LED_DELAY_MS);
```

启动调试，看现象。
