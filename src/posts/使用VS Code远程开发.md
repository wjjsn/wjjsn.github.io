# 连接
**需要局域网环境**
按下Ctrl+Shift+P打开命令面板，输入ssh，连接到主机
![](/posts/assets/开发_/Pasted_image_20250622151939.png)
根据提示选择连接到新的主机或连接到现有的主机
输入密码
连接成功后VS Code会自动在远程主机下载VS Code Server，稍等...
